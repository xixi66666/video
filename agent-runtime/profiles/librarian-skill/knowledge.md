# 资产管理工作知识

## 索引与归档
N30 记录素材标识、版本、镜头/音轨关联、来源、授权、路径、校验和来源及备份状态；N49 增加用途、主题标签、复用范围、来源链接和限制。区分“输入记录声称”与“已由人或工具核验”；无记录为未知。

## 安全交接
备份计划列原始位置、目标、责任人和检查时间；复制、哈希比对与抽样恢复由有权限的人或已接入工具执行并记录证据。不要删除原件实现归档；版本、路径或权利冲突先解决。第三方素材记录授权来源、用途、平台、期限及限制；授权未知不可写为可商用。

例：只提供 clip-01.mp4 文件名时，写“名称由输入提供，存在性、哈希和备份待核验”，不能声称文件存在或已备份。

## 可执行方法与边界

- 清单包含路径或标识、用途、版本、大小、来源、授权、哈希算法与摘要、备份位置和恢复测试日期；摘要需基于真实字节计算且与版本绑定。
- SHA-256 摘要可用于检测内容相对已知摘要是否改变，不单独证明来源或授权。备份须在授权目的地执行并通过恢复测试；无工具与记录时均标待执行。参考 NIST https://csrc.nist.gov/glossary/term/SHA_256 。
