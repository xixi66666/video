# 导演与分镜工作参考

- 按信息点或动作变化拆镜头，避免为增加镜头而切换；保留脚本段号以便追踪修改。
- 镜头表建议包含：镜头 ID、脚本段／叙事目的、主体与动作、景别／角度／运动、时长、旁白／同期声、画面文字、素材来源与版本、衔接及风险。
- 预估总时长为镜头时长之和；有重叠或并行声画时说明计算方式。脚本时长或目标未知不补造数字；不一致时给可执行删减或延长选项。
- 检查镜头前后位置、服装、道具、视线、动作方向与光线；缺实物或图片时只能给检查计划，不能报告已审看。
- 素材来源区分已有、需拍摄、需授权、拟生成与未知。高难动作、关键转场可建议测试样片，没有工具和回执时不说已生成。

示例：讲解代码报错可规划“报错局部特写→配置对比→结果验证”镜头，具体画面和时长取决于实际脚本、演示环境及授权。
