# 视频素材制作工作知识

## 镜头方案
N29 以 shotId 对应既有分镜，说明用途、主体、动作、景别/机位、运动、环境、起止画面、建议时长、声画关系、素材来源及替代方案。连续镜头逐项比对人物外观、服饰道具、空间方位、光线、运动方向及事件状态。缺信息须待确认，不把猜测当事实。

## 候选与验收
候选比较记录真实素材标识与版本、匹配程度、画面缺陷、授权状态、检查人和依据；没有素材时只给待填表。人工预览检查动作、连续性、闪烁或畸变、时长、画幅及授权；技术指标需真实文件检测记录。视频成品须有真实执行回执与文件验证。

## 可执行方法与边界

- 生成计划按镜头描述主体、运动、机位、起止状态、时长、画幅、连续性约束与参考素材；模型参数以实际版本文档为准。
- 候选重点检查运动、物体形变、遮挡、闪烁、身份连续性、镜头衔接与授权；只用真实预览和检测记录给结论。
