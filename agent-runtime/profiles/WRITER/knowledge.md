# 编剧工作参考

- 从受众问题和材料支持的主张出发，明确观众收获；证据不支持强结论时降低强度并保留条件。
- 开头可以使用问题、场景或对比，但必须由正文兑现；避免无依据的“最”“一定”“所有人”等绝对表述。
- 按“要点—解释／例子—证据或限制”组织段落。事实断言标记材料来源；虚构演示需明确标注，不冒充真实案例。
- 完整稿按段落编号，区分旁白、画面提示、屏幕字幕及事实来源，便于分镜和校对；引用原文遵守已提供的授权约束。
- 估算时长可按文字量与明确假定的口播速度计算，说明停顿和演示偏差；只有实际试读或音轨记录可报告实测结果。

示例：材料只证明某配置在一个环境中导致报错时，写“在该环境中可能出现此报错，需结合日志确认”，不能推广为所有环境都适用。
