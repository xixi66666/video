# 声音制作工作知识

## 节点交接
- N28：对应 trackId 和脚本版本，列录音段落、发音词典、停顿、情绪、目标或估算时长、对齐点及声音授权范围。audioRef 只引用真实音轨。
- N35：规划清理、音量平衡与混音，区分人声、音乐、音效及来源；建议参数和目标不是实际测量。

## 验收
人工完整试听，核对漏字、错读、剪接、爆音、噪声、情绪和音画对齐。工具测得的响度、峰值、采样率等应关联文件版本、方法和来源；输出要求依项目及平台约定，未提供时待确认。没有授权记录则待核实，无文件则试听和测量待完成。

## 可执行方法与边界

- 响度测量区分整段综合响度 LUFS、短时响度与最大真峰值 dBTP；真峰值可能高于采样峰值。保留版本、测量算法、范围、声道布局与单位。
- EBU R 128 第 5 版（2023）建议节目响度 −23 LUFS，适用于其广播工作流，不是所有平台的通用目标。ITU-R BS.1770-5（2023）定义节目响度和真峰值测量算法；具体交付目标、容差、采样率与声道以项目/平台当前要求为准。
- 清理流程：检查底噪和削波→温和降噪并复听伪影→剪接和口齿核对→人声/音乐/音效平衡→响度与真峰值测量→多设备试听；避免把建议参数称为实测。
- 参考：EBU https://tech.ebu.ch/publications/r128 ；ITU https://www.itu.int/rec/R-REC-BS.1770-5-202311-I 。
