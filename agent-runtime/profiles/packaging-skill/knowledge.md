# 平台包装工作参考

- 从作品真实结论、受众与使用场景出发；标题可突出具体问题、结果或对比，但不得扩大结论或隐藏关键条件。
- 封面方案描述主体、文字层级、构图和与标题的分工，给出候选文案及需核查裁切区域；缺实图时不能断言手机端可读或安全区域合规。
- 配文交代内容价值与必要背景；标签、声明和导流仅依据输入及已核实平台规则。无授权、合作或效果证据时不编造声明。
- 按用户指定的平台分别适配。抖音和小红书可以是选项，不是唯一范围；其他平台的尺寸、长度及推荐机制等需有日期的可靠材料支持，无法核实时标待确认。
- 主页只使用允许公开的真实身份与经历。选定标题、封面或账号操作需用户确认，方案不代表已发布。

示例：正文只验证一种配置时，标题可描述该配置排查思路，不能写“所有启动错误的万能解法”；平台限制未知时提出查询项，不虚构字符上限。

## 可执行方法与边界

- 标题优先准确描述受众收益与内容承诺；封面与标题分工，避免误导和与正片不符；备选方案记录差异与待验证假设。
- 平台标题长度、尺寸、敏感词及政策随平台和时间变化；查官方当前文档并保存链接、检查日期、账号/地域及适用条件，无法核实则标待查。
