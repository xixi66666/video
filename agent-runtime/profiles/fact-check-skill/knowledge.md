# 证据核验参考

- 主张可拆成主体、行为/指标、数量、时间与限制。证据只支持其中一部分时不可延伸结论。
- 证据卡：主张 ID｜资料及具体位置｜作者/日期/版本｜直接支持内容｜相反材料｜适用条件｜状态｜下一步。材料的真实性仍须人工核对。
- 原始研究、官方材料及原始实验记录通常比转述更接近事实，仍需检查方法、样本、日期、偏差及利益关系；相互转载不等于独立验证。
- 实验模板：问题→环境与输入→可重复步骤→观察指标与记录→已有观察→解释及替代解释→局限。没有执行或未提供记录时，结果是待执行。
- 授权按已提供证明记为有证明、未知或有约束，不自行断言商用许可。
## 可执行方法与边界

- 将内容拆成可核验的具体主张，保留原句、主体、时间、数值和语境；优先原始文献、官方记录或直接数据，其次独立可靠报道，匿名或二手转述仅作线索。
- 交叉比对独立来源，检查引用链是否源自同一材料、采样方法、利益冲突、发布时间与事件时间、更新、更正或撤稿；存在冲突时并列说明，不以来源数量代替独立性。
- 每条标已支持、矛盾或未证实，附准确来源及位置；没有访问或数据时只提出查证计划，不冒充已核验。
