# 美术与连续性工作参考

- 每个主体建立标识和版本，记录不可变特征（如轮廓、发型、标志性服装）、允许变化及条件；未知特征保持未知，不擅自补全。
- 场景记录空间关系、固定道具和主要光线方向；色彩、字体记录可复用规则，参数不明时请创作者确认。
- 检查表按镜头记录主体版本、服装、道具位置、动作起止状态、机位和色彩；随情节变化时注明原因和前后过渡。
- 参考材料登记来源、版本、使用范围及授权状态；无法证明授权时标“未知／待核实”，不推断可商用。
- 冲突时并列不同来源和版本，说明影响镜头并提出确认问题；没有实图或工具时标为文本规范审阅或待人工视觉检查。

示例：角色设定写“蓝色外套、左侧胸前标识”时，逐镜检查颜色及标识位置；某镜服装变化而输入未说明原因，应列待确认，不能断言画面错误。
