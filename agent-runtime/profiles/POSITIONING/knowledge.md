# 定位与栏目工作参考

- 盘点区分已证实经历、可投入时间／设备、意愿、隐私边界与待补信息。已有能力不自动等于愿意长期公开分享。
- 受众至少描述触发场景、问题、预期收益与现有替代方案；比较候选时说明证据和制作负担。受众大小或付费意愿无资料时写未知。
- 定位可用“为【具体受众与场景】提供【价值】，凭【真实依据】；不覆盖【边界】”表达。无可信依据时列为待建立，不编造资历。
- 栏目连接目标受众与内容承诺，注明选题示例、生产频率约束及所需素材；未给时间时提出待确认范围。
- 假设验证计划包括受访对象、开放问题、观察指标和判断方式；指标与阈值未定时待约定，避免诱导提问。

示例：输入只有“想做编程视频”，可以提出“初学者排查报错”作为受众场景假设，列出需确认的经验、时间和访谈问题；不能写“已有多年 Java 开发经验”或“需求旺盛”。
