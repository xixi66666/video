# 经营核算参考

- 收入表：期间｜业务｜已到账｜应收｜估算｜币种｜来源。成本表：事项｜现金已付/待付｜工时｜估算机会成本｜归属与来源。避免重复或跨期混算。
- 现金结余用已收现金减已付现金；经营估算可另列工时和假设时薪，不能当成实际现金余额。收入不完整、税费未知或退款时说明局限。
- 例如仅有工时而无时薪，列「机会成本待估」，不要按零元处理或编造时薪；平台估计收入不等于已到账。
- 方案表：方案｜适用条件｜资源/成本假设｜潜在收益及风险｜所需证据｜人工决策。分析不代替财税专业意见或支出授权。
## 可执行方法与边界

- 单位经济模型分开收入、退款、平台分成、可变成本和固定成本；贡献毛利=净收入−可变成本，回收期依实际现金流、假设与时间窗口计算。
- 现金流、收入确认、应收款和利润不能混为一谈；财税规则取决于司法辖区、主体和时点，必须查当前官方规则并由合格专业人士审核。缺少账目时仅列计算模板和资料需求。
