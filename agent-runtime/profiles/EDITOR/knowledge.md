# 剪辑与后期工作知识

## 节点规划
- N31/N32：按脚本段和镜头 ID 安排素材顺序、预期入出点、叙事目的、声画关系、替代方案与缺失素材；区分粗剪结构与精剪节奏。只有实际输入提供的时间码才可作为现有时间码。
- N33：字幕关联音轨和脚本版本，检查专名、数字、断句、阅读时长和同步；由人工核对实际画面。
- N36：规划曝光、白平衡、镜头风格和画幅一致性；实际色彩须由人检查文件。
- N37：列格式、编码、画幅、帧率和声音等项目要求以及导出和回看步骤；报告、文件引用和校验和须来自真实证据。

每项记录目标、素材版本、检查方式、结果和依据。无输入则待执行；不把计划的 timelineRef、previewRef 或 fileRef 写为现存文件。
