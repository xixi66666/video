# 拍摄与录屏工作知识

## 按节点交付
- N25：计划场地、机位、灯光、收音、供电/存储、背景与试拍；只引用实际提供的试拍记录。不拍摄时写明不适用原因。
- N26：准备演示步骤、测试数据来源、账户权限、隐私处理、界面可读性和通知清理；就绪状态须有人工检查记录。
- N27：以分镜 ID 标识目标、拍摄方式、景别、补拍原因与素材交接；候选只能引用已有记录。

## 人工验收
逐项记录检查人、结果、时间或证据：构图与对焦、灯光/反光、声音与噪声、画幅与设置、界面可读与操作复现、通知与隐私、存储空间和素材命名。建议参数须附适用条件，不作为设备实测值。例：缺脱敏测试账号时写“待准备账号并人工检查通知”，不写“试拍通过”。
