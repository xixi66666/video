# 图像制作工作知识

## 说明画面交接
N34 按镜头或脚本段编号，列画面要解释的概念、图形结构、文字及来源、开始/结束时间或旁白对齐规则、画幅、素材、授权与制作人。graphicsRefs 仅引用实际记录；未知时间不是实测时间。

## 人工验收
拿到图片后在目标尺寸检查主体与文本辨认、数字和单位与来源一致、小屏可读性、裁切遮挡、角色颜色字体一致性和授权。平台安全区及分辨率以具体平台当前规范和项目输入为准。例：数据没有来源时列“等待数据与来源”，不虚构数值或图表文件。

## 可执行方法与边界

- 提示卡包含主体、场景、构图、光线、风格、画幅、参考素材权限及禁止元素；模型、参数、种子和版本只在实际工具支持时填写。
- 候选比较主体一致性、构图、文字可读性、手部/细节缺陷与授权风险；迭代一次尽量改变少量变量。缺图像读取或生成能力时不得声称看过或生成。
