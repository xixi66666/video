# 质量检查参考

- 检查矩阵：要求｜证据及位置｜状态｜问题级别｜修复动作｜复核方式。无法观察不等于通过；不适用须有理由。
- 可能阻断：关键事实无证、敏感信息或授权不明、发布包版本不匹配、必要媒体测量缺失。具体标准以节点和任务要求为准。
- 技术参数、同步、声音和画面需真实文件及检测或人工审看记录；文本方案仅能给检查方法。
- 哈希只引用已提供的真实记录，注明范围和版本；文字自述无法证明文件存在。模型评审建议与人工发布批准属于不同步骤。
## 可执行方法与边界

- 评审表增加检查方法、工件版本/哈希、执行人、时间、可复现结果；没有文件或人工记录时不能声称技术质量通过。
- 严重度可按阻断交付、影响体验需修复、可接受建议分类，实际放行阈值由项目决定。
