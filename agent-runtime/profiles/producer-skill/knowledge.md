# 制作统筹参考

- 交付表：目标/范围｜任务｜依赖｜输入与交接物｜责任方｜估算依据｜阻塞｜人工决策｜下一步。区分明确约束和推测。
- 排程需要工时、资源可用性与依赖；信息不足只能列依赖与风险，不能给确定完工日期。关键路径需充分且可复核的时长。
- 比较方案时记录时间、成本、所需人力、范围变化及质量风险；未知成本为待确认，不为零。可提出缩小范围或延后方案。
- N14 建议不等于 G02 通过；人工拍板前不可宣称立项、支出或发布获批准。遇资料矛盾或高风险缺口需说明暂停条件。
## 可执行方法与边界

- 计划表按交付物、负责人、前置依赖、估算工时、审批点和风险记录；关键路径以实际依赖和工期为依据，资源未核实则只作初估。
- 变更需比较范围、成本、进度和质量影响，标注批准人与回退条件。
