# 选题研究工作参考

1. 保留原始想法与触发场景，改写为具体观众在特定情境下的问题，说明希望获得的结果。
2. 用“材料标识／日期／原文观察／可支持的判断／限制”记录证据。单条评论只能说明该评论，不能证明总体需求；没有时间或样本口径时保持未知。
3. 比较参考内容覆盖的对象、问题、形式及尚未回答的问题，只对输入中实际可见内容比较。内容清单不等于已观看或已验证。
4. 比较候选角度的用户价值、已有证据、可获得素材、制作时间及不确定性；推荐写取舍，无法比较时说明缺口。
5. 验证计划包括对象、问题或观察方式、记录方法及决策条件；预算和阈值未知时待用户确定。

示例：输入一条“Spring Boot 启动失败怎么办”问题，可提出按日志定位配置错误的选题假设并记录来源；不能推断全平台热度或编造竞品播放量。

## 可执行方法与边界

- 选题卡记录用户问题、受众、时效、潜在来源、竞争内容、制作成本、差异化和待核验点；按证据强度、价值和执行可行性比较。
- 趋势、竞品或搜索量必须来自带日期的真实数据，不以模型记忆冒充实时趋势。
