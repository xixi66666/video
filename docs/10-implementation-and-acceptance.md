# 10 开发顺序与验收清单

## 1. 当前阶段 P0：文档交付

交付本项目文档、50 节点注册表、19 职责、25 能力、6 个拍板、三类模板、Schema、脱敏示例和文档校验。没有运行中的业务功能；所有连接器都未实现。

## 2. 后续阶段与退出条件

| 阶段 | 实施内容 | 必须满足的退出条件 |
| --- | --- | --- |
| P1 全流程管理 | 前后端基础、档案/灵感/项目、全部节点、文件、版本、人工交付、拍板、任务与模型配置页面 | 不接外部生成工具，也能手工完成 50 节点并明确记录发布和复盘 |
| P2 可配置智能执行 | 优先实现用户实际模型协议、能力测试、角色提示词、结构化产物、路由、预算与有限重试 | 至少两种不同协议验证；选题到脚本分镜可自动推进到 G03；不兼容模型被拦截 |
| P3 模板化制作 | 媒体检查、字幕、合成、预演；人工剪辑交接 | 采用素材可生成可检查预览；修改旁白只影响相关范围 |
| P4 异机工具接入 | 按文档在目标环境实现 ComfyUI 等连接器，逐个验证 | 真正提交、对账、文件回收、异常和恢复通过，才标记 VERIFIED/ENABLED |
| P5 发布与反馈自动化 | 有权限的平台逐一接入；否则保持人工发布与导入 | 准确区分草稿/提交/审核/可见；发布授权绑定确定版本；指标口径可追溯 |

阶段是开发顺序，不是删减业务范围。P1 就有全部 50 节点，后续替换执行方式，不重新发明业务目录。

## 3. P1 可抓取的开发任务

1. 工程与契约：身份、错误格式、节点定义读取、版本迁移、文件上传。
2. 模型中心：Provider/Model/能力/预设/绑定表单，解析和干运行；未实现协议明确标识。
3. 工作流：范围实例化、依赖、草稿与阶段边界、人工任务、跳过原因。
4. 产物与镜头：版本、来源、候选采用、依赖、影响预览。
5. 确认中心：G01—G06、版本差异、失效、并发校验。
6. 制作与后期：拍摄/录屏清单、人工结果、字幕校对、审片问题单、母版交付。
7. 发布与复盘：两平台发布包、人工记录、评论/指标导入、经营账目与资产归档。
8. 系统：任务/费用/事件、导出导入、备份、权限和脱敏。

## 4. 全节点覆盖验收

- 节点定义 N01—N50 连续且名称对应原始流程。
- 三类模板都展示全部节点；不适用有原因，未接入有手工交付入口。
- 每个节点可以读取输入、保存产物、记录版本、查看来源、说明分工与检查要求。
- ACCOUNT/IDEA/PROJECT/SHOT/TRACK/PLATFORM 作用域都有实例化示例。
- 19 个职责有工具边界和可选模型，25 类能力是筛选标签而不是必装服务。

## 5. 关键验收场景

| 场景 | 预期 |
| --- | --- |
| 新用户无模型配置 | 可建档和手工运行，不伪造 AI 产物 |
| 已有账号档案 | 绑定旧版或新建档案版本，不重复执行全部基础节点 |
| 同一用户多个文本模型 | 可按 Agent、项目、节点切换；继承来源可见 |
| N28 多能力 | TTS、ASR、对齐可分别选模，未支持能力不硬调用 |
| 模型参数不兼容 | 阻止提交并定位字段，不悄悄丢参数 |
| 修改全局默认 | 已运行快照不变，后续任务预览显示新来源 |
| 不支持模型列表接口 | 可手工登记并测试，功能不被卡死 |
| 超时状态未知 | 转对账，不立即重复提交或换供应商付费 |
| 工具未接入 | 显示未接入、导出要求、接收人工结果，后续可继续 |
| 8 镜头仅完成 6 个 | 项目粗剪/交付等待其余必需镜头或明确替代 |
| 修改 S004 旁白 | 相关对齐、字幕、时长及成片待复查，其他镜头不重生成 |
| 两平台包装不同 | 独立版本与 G04/G05；一边失败不影响另一边真实性 |
| 两人/两窗口同时确认 | 只有匹配当前版本的决定成功，旧窗口 409 |
| G05 后换封面或账号 | 原授权失效，不使用旧授权发布新包 |
| 平台只支持立即发布 | N42 不假装草稿；实际发布必须在 G05 之后 |
| 导入人工发布链接 | 保留人工来源、检查时间和状态，不虚构 API 凭证 |
| 评论回复 | 草稿与已发送分开；对外发送有明确授权 |
| 数据缺失 | null/未知不变成 0；时间窗与平台口径可见 |
| 自动运行超预算 | 停止新派发，保留已完成产物和真实消耗 |
| 重启 Worker | 从任务租约和外部凭证恢复，不丢失或盲重复 |
| 迁移另一台机器 | 配置无密钥，重映射目录/凭据后重新探测执行环境 |

## 6. 建议测试层次

单元：继承解析、参数验证、预算计算、状态转移、影响分析。集成：数据库事务、幂等、租约、事件重放、上传与权限。契约：各适配器的请求/响应、错误和异步生命周期。端到端：三类内容模板、两平台发布包、人工降级和六个拍板。

媒体回归使用少量有代表性的样片与检查指标，不把所有视频逐像素比较当稳定标准。真实供应商与工具联调只在目标环境授权和预算具备后进行。

## 7. 当前文档验收

`python scripts/validate_docs.py` 检查目录、引用和语义关系；`python scripts/render_node_catalog.py --check` 检查节点文档是否与注册表一致。它们不验证真实 API、GPU 性能、生成质量和平台账号权限。

## 8. 开发启动约定

后续开发先读取 README、PRODUCT、节点目录、模型配置和工作流文档。先跑通小型可演示路径，同时保持 50 节点导航与手工入口；不要将首版做成只有一段聊天或只有 ComfyUI 提交按钮的页面。
