# 01 产品与范围

## 1. 交付状态

当前为设计交付：实现文档、规格与脱敏示例。本文中的页面、接口、表、模型调用和执行器均为**拟实现合同**，不得对外宣称已经可用。本次不创建应用框架、不安装 GPU 软件、不进行真实调用。

## 2. 一条完整业务链

创作基础 N01—N07 → 想法与选题 N08—N15 → 资料脚本 N16—N24 → 素材制作 N25—N30 → 后期 N31—N37 → 包装与发布 N38—N44 → 反馈复盘 N45—N48 → 资产 N49 → 经营 N50。

50 个节点是业务目录，不是每次都串行执行的 50 个按钮：账号档案可复用；多个镜头和平台版本可以并行；实拍专属节点在纯 AI 项目中以明确替代路径执行或标记不适用。

## 3. 分工模型

- A：在确定输入、可验证规则、已授权预算内，Agent/程序独立执行；异常才交给人。
- B：Agent 制作或研究，人补充真实信息、选择候选并确认；按阶段集中审阅。
- C：人主导现实操作、业务方向或对外承诺；Agent 提供方案、清单和执行支持。
- A/B/C 是当前基准，不是质量保证。具体节点的模式由内容类型、能力实测及政策约束共同决定。

人拍板只绑定明确版本、目标和范围。六个阶段拍板见 `specs/gates.json`；日常候选素材可局部采用，不必反复审批同一个决定。

## 4. 自动化模式

| 模式 | 行为 |
| --- | --- |
| GUIDED | Agent 给建议与草稿，用户主动启动下一步 |
| AUTO_UNTIL_GATE | 自动执行就绪任务，到拍板、缺输入、预算不足或未接入时停止该分支 |
| TEMPLATE_BATCH | 对已确认的模板、镜头和预算批量执行；保持阶段拍板 |

默认 AUTO_UNTIL_GATE。批量操作不是“无限重试”或“自动批准”；所有外部副作用仍受授权范围限制。

## 5. 首版必须可管理的对象

定位、灵感、选题、来源、实测、脚本、分镜、视觉设定、动态预演、拍摄计划、录音、素材候选、剪辑版本、字幕、混音、封面、发布包、发布记录、评论、指标、复盘、资产、成本收入。

动态预演、风格样片和逐镜验收作为 N24/N27/N29 的子任务，不新增或替换原有节点编号。

## 6. 明确边界

1. 全部 50 节点首版都有入口、输入输出和手工完成方式；复杂自动执行可分期接入。
2. 模型可配置不等于任何协议都自动兼容；服务商、适配器和能力探测分别建模。
3. ComfyUI、OBS、剪辑软件、发布平台等当前仅预留合同和接入说明。
4. 首版不建设通用网页剪辑器、不训练专用大模型、不建设大型多租户平台。
5. 没有平台接口权限时交付发布包，由用户上传并导入结果；不能用“已导出”冒充“已发布”。

## 7. 路线与范围复用

REAL_PERSON：实拍优先。SCREENCAST：真实录屏 + 旁白。AI_STORY：参考设定 + 生成镜头。三者均保留 50 个节点。账号节点按 profile_revision 复用；镜头、音轨和平台节点按 scope_key 多实例展开；N48/N50 形成新项目或新迭代，不回写形成工作流环。

## 8. 范围不确定项

部署硬件、模型列表、可接受成本、素材风格、账号权限均不假定。它们不阻止本次文档完成；在后续环境登记和样片验证时补齐。
