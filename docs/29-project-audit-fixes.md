# 本机工作台整体验证与修复

本次检查覆盖前端数据源、Java 业务事务和任务投递、Python Agent 运行状态、启动脚本及隔离测试。测试使用 FIXTURE、模拟端点和隔离数据库；没有调用付费模型或执行真实发布。

## 修复

- 工作区首次初始化、Agent 运行创建和草稿采纳的事务锁延续到提交或回滚，避免并发请求看到未提交状态；保留工作区版本比较。素材生成任务的取消和提交进行协调，并在上传参考素材和提交前重新检查状态。
- Agent 投递在请求前记录尝试；取消意图先持久化，不再重复提交生成。取消同步失败保留待核对状态，重试不会擦除可能已投递的历史。运行已删除时不能采纳；调度器使用独立待处理查询，避免最近 200 条记录限制导致旧任务被遗漏。
- Python 运行时按完整事件集计算模型调用次数；任务入队、创建事件、取消和终态事件的关键更新在同一数据库事务内完成。重复取消保持幂等。恢复时对真实模型的每次调用重新检查服务器开关和当前白名单；调用已开始后无法承诺撤销供应商请求。
- 角色 Skill 和知识只有完整、未截断地读取后才满足提交条件；第三方异常不向工作区返回原文，避免意外泄露凭据或敏感输入。
- 前端刷新失败时保留当前服务端数据，刷新与保存串行；本地模式不能误启动服务端协作。断线、删除与取消同步状态有明确反馈。
- 本机 API 限制 Host 为回环主机，避免通过 DNS 重绑定同源读取本机数据；仍不等于多用户身份认证。默认启动和 DeepSeek 启动在部分进程启动失败或超时后回滚已启动进程，前端不继承内部令牌；默认 FIXTURE 入口不向子进程传递 DeepSeek 密钥。
- 浏览器联调继续使用隔离数据库和临时端口；清理临时目录前检查真实路径和本次实例标记，并避免测试进程继承 DeepSeek 密钥。

## 验证

- Python 运行时全量测试：153 项通过，包含并发恢复、取消幂等、完整读取和启动脚本回滚测试。
- Java 后端全量测试：54 项通过，离线打包成功，包含投递、事务及媒体取消竞态测试。
- 前端：30 项单元测试通过，生产构建成功；隔离前后端浏览器联调 31 项通过。
- 文档与节点目录检查通过；隔离联调的临时数据已按实例标记核对后清理。

## 范围与剩余限制

该版仍是单机工作台，不支持多副本运行保障或生产级身份认证。真实媒体 Worker、发布、视觉识别和完整音画质量验收仍未接入；一次真实模型试验不能证明 19 个角色的领域专业能力。项目侧 token 限制仍按用户要求关闭，供应商计费及自身限制继续适用。正在执行中的远端模型或媒体请求不能保证撤销，取消状态应以供应商或 Worker 的实际回执为准。

修复之前已经处于 `PENDING_SUBMISSION` 且投递尝试计数为零的旧记录，无法仅凭本机记录判断它是否曾被远端受理；升级后处理这些旧排队任务前，应先核对远端状态。新的投递会在发送前持久化尝试记录。
