# 09 安全、预算与质量标准

## 1. 凭据与网络

所有示例只保存 credentialRef，配置导出、日志、提示词、异常响应中不包含真实密钥。生产凭据使用环境或受保护存储，若入库必须应用级加密且主密钥不与数据库一同备份；浏览器不能读取服务商密钥。

服务商和工具地址由用户/管理员登记，不由模型自由指定。校验协议、域名/IP、重定向目标和 DNS 解析；私网目标需明确白名单；防止把远端访问功能变成任意网络请求。下载限制大小、超时和类型，文件名规范化，禁止路径穿越。

工具权限按 Agent 和任务划分：读取资料、调用模型、写项目产物、发送消息、发布、删除、安装依赖分别授权。不因当前处于自动模式就允许所有工具操作。网页、评论和导入文件中的指令作为不可信数据处理。

## 2. 内容与授权

source_record 保存来源、日期、引用位置与证据；rights_record 保存音乐、字体、图片、人物、声音等使用范围和授权凭证。工具开源不等于模型、字体、声音或素材可随意商业使用。

真人经历由用户提供；实测保留真实输入与输出，不把生成图当证据。AI 内容、演绎和商业合作的声明按发布时适用规则及平台发布页填写。G04 检查，G05 确认最终对外版本。

当前不预设任何具体用户账号已具备发布、评论读取或商业化权限。

## 3. 预算模型

预算范围：预览、项目、阶段、节点、执行尝试；支持 token/字符/秒/张/任务/GPU 时长等计费。示例中的 100 元只是演示预算，不是制作成本预测。

事务约束：`spent + reserved + next_reservation <= authorized_limit`。运行结束按真实凭证结算，释放剩余预留。估计、供应商回报、人工账单、实际确认分开记录，金额未知为 null，不能用 0 掩盖未知。

重复回调去重；取消可能仍计费，保留最终账单；自动回退算新尝试并占预算。不能因为换服务商而重置节点重试上限。超过并发、次数、时长或金额任一边界就暂停该分支。

## 4. 检查分层

| 层 | 例子 | 能否独立认定可发布 |
| --- | --- | --- |
| 文件与结构 | 可解码、时长、尺寸、帧率、音轨、JSON Schema、哈希 | 不能 |
| 内容辅助检查 | 漏读、字幕专名、声画对应、角色漂移、缺镜头、标题一致性 | 不能，输出问题和证据 |
| 人工内容判断 | 真实、表达、审美、承诺、隐私、授权范围 | G04 的必要判断 |
| 发布授权 | 平台、账号、版本、可见范围、时间 | G05 的明确授权 |

检查程序报告黑帧/静音不自动认定错误，要看是否为设计；VLM 可能漏检动作和连续性；ASR 不能证明发音永远正确；Schema 不能证明观点真实。

## 5. 样片与质量门槛

G03 前先测试代表性难镜、中文专名配音和风格样片。每种模板定义“必须通过、警告、人工判断”三类规则。不设未经验证的统一完播率、响度或“爆款分数”。导出规格和声音目标由项目预设确定。

生产返工分为技术失败和内容失败。技术失败可有限自动重试；内容失败需要新条件或制作方法。保存修改原因和采用结果，避免用随机重抽代替解决问题。

## 6. 模型与模板评测

每个常用能力保存少量有代表性的验收样例：中文脚本、术语 TTS、字幕对齐、人物多镜头、图表中文字、模板导出。更换模型、节点、提示词或适配器后复测。

记录可用产物率、人工修改时间、端到端耗时和实际成本；不能只按单次调用价格选型。自动评审与生成可用同一服务但要标明相关性，关键事实和发布仍由人判断。

## 7. 数据与经营复盘

指标保存平台口径、时间窗、导入来源和缺失状态。不同平台的播放量、曝光、观看时长可能不具备直接可比性。用户删除数据后，依赖其形成的结论标记需复查。

经营看板分开成本、收入、未回款、工时和业务线索；不将“有人问价”自动计为收入。N50 由人决定继续、调整或停止。

## 8. 日志与审计

记录 actor/request/task/attempt/model_snapshot、版本、参数摘要、工具和外部请求 ID、耗时、费用、状态变化。默认最小化保存提示词和原始个人资料；敏感内容先脱敏或限制留存。保存可审查的行动理由，不收集隐藏思维链。

## 9. 删除、备份和恢复

删除采用文件前检查所有引用；默认软删除和保留期，真正删除需明确范围。备份数据库、原始/采用素材、模板与配置；缓存和代理文件可重建。至少通过一次恢复演练后才称为“有可靠备份”。配置备份不含可直接使用的密钥。
