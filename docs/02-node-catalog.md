- 推荐能力用于选模；手工导入不要求对应模型已经接入。
- 输出用 artifactType 和 payload 必需字段约束；下列文字规定字段语义与检查。
- 同阶段可组装标记 DRAFT 的草稿，正式生产和发布受阶段确认限制。
- 不适用须说明及替代，未接入须手工交付或阻塞，不能伪造执行成功。
- 状态、拍板、局部返工和聚合见 [工作流文档](03-workflow-and-agents.md)。
