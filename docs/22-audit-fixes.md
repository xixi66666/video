## 验证命令

要求 Node 22.6+、Java 21+、Maven 3.6.3+，以及已安装的项目 Python 运行环境。

```powershell
cd frontend
npm test
npm run build
npm run test:e2e
cd ../backend
mvn clean test package
cd ../frontend
npm run test:e2e:backend
```

若 Java 或 Python 不在默认位置，设置 `JAVA_HOME` 和 `CREATOR_RUNTIME_PYTHON`。联合测试运行全部浏览器用例；可在命令尾部指定测试文件。不要用 `PLAYWRIGHT_API_URL` 指向日常工作区运行测试，服务地址和实例标记由隔离脚本自动生成。

此轮不改审批作用域、不进行真实模型调用或发布、不扫描或输出现有用户数据库中的敏感值。
