# 07 页面、操作与状态设计

## 1. 使用方式

界面为 PC 优先的操作型产品。主任务是知道“现在该做什么”，并在同一项目中找到模型、素材、版本、确认和费用。首页不堆模型排行榜和装饰图表。当前仅页面规格，没有可点击原型或已实现界面。

## 3. 项目工作区布局

左侧：按阶段展示 50 节点，显示账号档案复用、条件跳过和子实例数量；可切换 DAG 高级视图。中间：当前节点的输入、编辑/预览、候选与主要操作。右侧：模型解析、上下文来源、版本、预算、检查与确认信息。

镜头表至少：镜头 ID、画面目的、对应旁白、预计/实际时长、制作方式、采用版本、状态、费用、下一步。平台表至少：平台、账号、发布包版本、G04/G05、时间与实际可见状态。

不能只显示“项目完成 80%”；要写“8 个必需镜头已采用 6 个，1 个待选，1 个因工具未接入等待上传”。

## 4. 模型配置交互

1. 新建服务商：协议、地址、认证引用、超时、限流和网络范围。
2. 手工登记模型或可选拉取：真实模型 ID、显示名、能力与限制。
3. 展示声明能力和已验证能力，测试之前说明可能消耗费用。
4. 参数表单由模型参数描述生成：数字范围、枚举、必填、默认值、供应商映射。
5. 选择全局/Agent/项目/节点绑定，可清除覆盖并回到继承。
6. 节点选择器按当前能力过滤，禁用项说明“未验证”“不支持图片”“长度不足”等原因。
7. 执行前显示实际模型、服务商、参数、输入范围、估算/未知费用和授权边界。

密钥写入后只显示状态与可辨识的引用，不回填真实值。新增模型不是改业务代码；协议不支持时明确提示待开发适配器，不假装通用。

## 5. Agent 对话与按钮协同

对话可请求“把 S004 改成录屏”“用另一个模型重写开头”。Agent 先返回变更计划，系统解析成允许命令；真正执行由工作流服务校验。对话不替代项目数据库；关闭聊天后进度不丢失。

主要操作：生成方案、开始执行、上传人工结果、比较版本、采用、退回修改、暂停、重试、预览影响、提交阶段确认。对话中一句“看起来不错”不能自动成为发布授权，除非展示并确认了具体授权目标。

## 6. 审片与采用

播放器支持时间点和区间问题，关联具体产物版本。问题类型：事实、字幕、声画、连续性、声音、画面、授权、技术。对比时显示版本和修改摘要；“采用素材”和“批准成片”是不同操作。

G03 展示脚本分镜、试听、预演和难镜样片；G04 展示成片与各平台包装；G05 只展示确定的发布目标与必要差异。不要为了审批展示整段内部日志。

## 7. 关键异常页面

| 状态 | 应显示与允许的动作 |
| --- | --- |
| 首次使用 | 建档、登记模型、选择模板；允许仅手工运行，不强迫配置所有模型 |
| 未接入 | 接入说明、任务要求、导出制作包、上传结果；不显示虚假生成按钮 |
| 模型未验证 | 已声明能力、缺失测试、测试预算和执行入口 |
| 等待人工 | 具体缺少的材料或决定、候选与建议、后续影响 |
| 预算不足 | 已用/预留/估算、触发原因、降低范围或追加预算 |
| 受影响 | 上游变更内容、需复查或重做的局部范围、估算 |
| 执行状态未知 | 远端受理证据、对账入口、禁止盲目重复提交 |
| 确认已过期 | 原批准版本和当前版本差异、重新确认入口 |
| 远端离线 | 最后心跳、任务状态、重连与手工替代 |
| 发布审核中 | 提交凭证、真实审核状态与检查时间，不写“发布成功” |

## 8. 可用性验收

键盘能完成选模、编辑与确认；焦点可见；状态不只用颜色；错误定位到字段。表格长文字可展开；上传、生成与导出有明确状态。中文为主，供应商原始错误作为可展开信息。小屏优先待办、预览和确认，不宣称实现完整专业剪辑体验。

## 9. 示例数据

演示项目、镜头、费用和模型必须标注“示例”。默认不展示虚构粉丝、播放量、收益和已发布作品。首次空态解释怎样开始，并保留全流程导航。
