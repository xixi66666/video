# 专家协作与工具：已实现能力和边界

本工作副本支持可选的跨角色会诊、受限研究工具和本地素材只读工具。知识和测试模型验收不等于真实领域能力认证；`domainVerified` 保持 false。

## 使用会诊

在工作台「协作运行」选择作品和节点，可选最多六位不同于主责的会诊专家。主管按勾选顺序串行委派，各专家只读取自己的角色包与原始节点输入，独立提交意见、来源和不确定性；主责综合后提交候选，评审可查看意见，仍需人工采纳。候选保存意见及角色配置哈希，事件和各版会诊产物可追溯；返工会重新会诊。多人共享同一预算，人数增加或返工时可能耗尽调用次数或运行时间，并非保证六人一定完成。

内部运行服务 `POST /runs` 的可选 `consultationRoles: ["FACT_CHECK", "WRITER"]` 省略或为空时沿用单专家链路。新运行会为每个会诊角色按作品、角色和全局绑定规则解析独立模型快照，并与主管、主责专家和评审模型一同经过明确的服务端白名单校验；配置可以不同，也可能继承同一个模型。旧运行没有会诊模型快照时仍沿用原主责 worker 配置。会诊共享模型调用和时间预算；会诊时调用上限从 30 增至 60，项目不再设置 token 阈值，但供应商自己的上限仍然适用。真实模型调用可能产生额外费用；角色串行执行，最多六名会诊专家，不是 19 名专家同时辩论，也没有自动裁决分歧。测试模型意见仅为链路占位。

工作台新建两位及以上会诊的运行会要求主责专家提供意见对照。对每个模型标出的潜在分歧，系统验证至少两位不同角色的逐字引用分别存在于其会诊意见、来源或不确定性中，并保存该意见的哈希以供追溯；允许列表为空。如果模型漏填或误引，对照标为待人工核对并保留原始意见，不让无效对照冒充有效结果，也不因此丢弃候选。**校验只能证明引文来自对应意见，不能证明事实正确、引文语义对立或摘要完整；空列表也不证明完全一致。** 是否存在分歧及如何处理由人工判断。旧运行快照没有对照要求，仍可按原协议恢复。

独立评审必须成功读取自己的 Skill 与知识，两者均读取成功后不再向模型提供 `read_file`，避免反复读取而耗尽调用；评审仍需通过 `submit_review` 输出具体结论，不能自动替代人工采纳。读取事件只记录目标类别与成功状态，不记录路径或文件内容；历史事件缺少这些字段，不能据此判断旧运行重复读取了哪一个文件。此调整通过离线模拟，并在一次隔离的 DeepSeek 真实运行中完成模型评审；这不代表其他供应商和全部场景均已验证。

## 可选专业工具

默认不开启真实模型或以下访问；FIXTURE 模式即使配置了开关也不会获得联网和主机文件工具。仅在 LIVE、角色允许、运行快照包含工具且管理员开启时注册。旧快照不会因为升级获得新权限。

- FACT_CHECK、TOPIC_RESEARCH、PACKAGING、PUBLISHER、BUSINESS：`read_research_page` 读取允许主机的 HTTPS 页面；`search_research_sources` 通过部署者配置的搜索服务取线索。部署环境需设置 `CREATOR_RESEARCH_ENABLED=true`、`CREATOR_RESEARCH_ALLOWED_HOSTS`（逗号分隔的精确主机名）；自定义搜索还需 `CREATOR_RESEARCH_SEARCH_URL`，接受 GET 查询参数 `q` 并返回约定 JSON。也可显式设置 `CREATOR_RESEARCH_PROVIDER=deepseek`，使用固定的官方搜索端点及 `DEEPSEEK_API_KEY`；可能计费。已在虚构查询上完成一次真实搜索，保存了 [来源样本](../agent-runtime/evals/deepseek-search-smoke-20261028.json)，并成功读取官方文档页面。搜索结果不是已核验事实，结果域名也不会自动加入允许列表。工具不跟随重定向、校验证书并限制响应；页面读取固定公网解析，DNS 解析和响应头读取没有严格整体墙钟上限，生产部署仍需出口限制与外部超时隔离。
- LIBRARIAN、QUALITY、AUDIO、IMAGE、VIDEO、EDITOR、ART_CONTINUITY：设置 `CREATOR_LOCAL_MEDIA_ENABLED=true` 和 `CREATOR_LOCAL_MEDIA_ROOT` 后，可对管理员控制的专用素材目录中平铺普通文件计算 `local_sha256`。安装并配置 FFprobe 后，`inspect_local_media` 可尝试读取 JPEG、WebP、MP4、WebM 等媒体元数据；显式选择响度分析且 FFmpeg 可用时，可测第一音轨最多前 120 秒的 LUFS 与真峰值。无 FFprobe 时仅对 WAV/PNG 回退文件头。格式支持与实际文件可读取性取决于工具构建；失败不能伪造结果。大小、目录、协议、进程超时和安全限制详见 [本地媒体探测](28-local-media-probe.md)。这些信号检测不等于完整媒体解码或成片内容验收。
- ANALYST、BUSINESS、FEEDBACK 可对显式传入的数字计算描述统计和 Wilson 置信区间；DIRECTOR、EDITOR、VIDEO、CAPTURE、QUALITY 可按给定有理帧率换算帧数时长。这些工具不自动采集数据或证明因果，不提供时间码转换。

标准 `scripts/start-local.ps1` 强制关闭 LIVE；上述配置不会自行打开模型调用。真实模型需要额外按 [运行说明](20-multi-agent-runtime.md) 配置并获得明确授权，不能把模型白名单、工具配置或模拟测试视作真实服务验收。不要将密钥写入源码或文档。

`/profiles` 的 `declaredTools` 是当前角色能力声明；`availableTools.FIXTURE` 和 `availableTools.LIVE` 按当前模式、管理员配置及当前声明给出可注册工具。兼容字段 `tools` 仅列测试模式当前可用工具。具体运行仍受其固定快照约束；注册状态不能证明来源或服务一定可用。角色 ID 保持稳定，Skill 目录使用小写连字符名称，旧运行仍读取其已固定的 Skill 快照。

## 仍未实现

尚无平台趋势/账号/发布/回执连接、评论或账目导入、自动试听与视觉识别、音画同步或画面一致性判断、生成、录屏、剪辑渲染或文件备份。一次真实搜索和页面读取不等于搜索质量及稳定性已全面验收。可选的本地媒体元数据和部分音频信号检测不代表已经审听、审看或完成验收。工作台的远程媒体 HTTP 协议不等于真实 Worker 已部署，见 [媒体协议说明](26-production-lottery-and-media-api.md)。平台规则和税务要求需要按当前时间和地区核验。

[评测说明](../agent-runtime/evals/README.md) 提供 57 条虚构场景、人工评分与基线配对汇总；DeepSeek 已完成隔离的 ANALYST 主管委派、候选和模型评审链路，最终代码的[试验记录](../agent-runtime/evals/deepseek-smoke-20261028-final.json)保留候选、评审和事件。该运行不写入实际工作区；模型评审不能代替合格专业人士的独立领域评分，其他专家也尚未完成真实评测，不应以合同测试或少量样本认定专家专业水平。
